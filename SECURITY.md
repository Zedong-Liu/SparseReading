# Security policy

Please do not disclose a vulnerability, credential leak, or exploitable
workspace escape in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/Zedong-Liu/SparseReading/security/advisories/new)
when it is available. If private reporting is unavailable, open an issue with
only the minimum information needed to request a private contact channel.

When reporting a security issue, include the affected release or commit, host
framework, operating system, reproduction conditions, and a minimal
non-sensitive proof of impact. Do not attach API keys, private files, or full
agent transcripts.
