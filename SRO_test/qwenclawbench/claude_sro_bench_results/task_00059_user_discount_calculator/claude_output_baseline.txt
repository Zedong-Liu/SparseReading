`discount_calculator.py` is written and fully verified. Here's a summary:

### What it does

The script computes discount percentages for users by applying the rules in `data/discount_rules.json` against user records in `data/users.csv`:

| Component | Logic |
|---|---|
| **Inactive override** | `is_active=False` → **0%**, regardless of everything else |
| **Tier discount** | bronze=0%, silver=5%, gold=10%, platinum=15% (from JSON) |
| **Loyalty bonus** | +3% if signup ≥ 2 years before 2025-07-01 (per JSON `years_threshold`) |
| **Spending bonus** | ≥$1,000 → +2%, ≥$3,000 → +5% — **highest-match only, not stacked** |
| **Cap** | Final result clamped to **25%** |
