### 3 High-Severity Bugs Found

| Bug | Description |
|---|---|
| **B1 — SSE truncation** | The SSE fetch only gets page 1 (30 announcements max), while SZSE paginates through 3 pages. On heavy disclosure days, 100+ SSE announcements could be silently missed. |
| **B3 — Random `seen_ids` trimming** | `list(seen)[-5000:]` on a set is order-arbitrary — you're not keeping the most recent IDs but a random slice, so old announcements can be re-fetched over time. |
| **B5 — Crash-safety ordering** | State is saved *after* the output file. If a crash hits between them, the next run duplicates data into the output. |
